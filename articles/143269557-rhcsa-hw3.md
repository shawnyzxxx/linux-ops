# RHCSA第三次课练习

## 文章导读
本篇是 RHCSA 课程第三次课的文件操作练习，围绕 **cp 复制、tar 打包压缩与解压、标准输出/错误输出重定向** 等基础命令展开，适合 Linux 入门阶段的读者巩固命令行基本功。

## 一、练习题目
1. **#18** 复制 `/var/log/messages` 到 `/root` 目录下
2. **#19** 打包并压缩 `/root/messages` 和 `/root/etc/` 为 `/root/me.tar.bz2`
3. **#20** 解压 `/root/me.tar.bz2`
4. **#32** 列出目录 `/root` 和 `/aaaaa`，将标准输出重定向到 `ok.file`，标准错误输出重定向到 `erro.file`
5. **#33** 列出目录 `/root` 和 `/aaaaa`，将标准输出和标准错误输出都丢掉

## 二、参考命令
**#18 复制文件**
```bash
cp /var/log/messages /root
```

**#19 打包并压缩**
```bash
tar -caf /root/me.tar.bz2 /root/messages
tar -caf /root/me.tar.bz2 /root/etc/
```
> `-c` 表示创建，`-a` 自动识别压缩格式，`-f` 指定压缩文件名。

**#20 解压**
```bash
tar -xf /root/me.tar.bz2 -C /root/
```
> `-x` 解压，`-C` 指定解压目标目录。

**#32 分别重定向标准输出与标准错误**
```bash
ls /root      1>/root/ok.file   2>/root/erro.file
ls /aaaaa     1>/aaaaa/ok.file  2>/aaaaa/erro.file
mkdir /root/aaaaa/erro.file
```

**#33 丢弃输出**
```bash
ls /root   1>/dev/null 2>&1
ls /aaaaa  1>/dev/null 2>&1
```
> `1>/dev/null` 丢弃标准输出，`2>&1` 把标准错误也丢弃，实现「输出全部丢掉」。

## 三、小结
本次练习覆盖了 Linux 中最常用的文件处理与输出重定向技巧。掌握 `cp`、`tar` 以及 `>`、`2>`、`&` 的组合，是后续运维工作的基础，务必多动手练习。
