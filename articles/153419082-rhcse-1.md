### 2. 仓库建立

**挂载镜像**
```bash
mount /dev/sr0 /mnt
lsblk -fp        # 查看挂载情况
```

**自动挂载**
1. 编辑 `/etc/fstab`：`vi /etc/fstab`
2. 写入挂载信息
3. 编辑仓库信息：`vi /etc/yum.repos.d/bendi.repo`
4. 查看已建立的仓库：`tree /etc/yum.repos.d/`

**下载 bash 补全并重启生效**
```bash
yum -y install bash-completion
reboot
```

**测试连通**：`ping baidu.com`

## 二、文件操作

**复制粘贴（cp）、重命名、移动（mv）**

示例：复制 haha 到 `/mnt/xixi/haha1/haha2` 目录，将其中的 haha 重命名为 haha_newname，再移动到 `/mnt/xixi/haha1` 目录：

```bash
cp -r haha /mnt/xixi/haha1/haha2/
mv /mnt/xixi/haha1/haha2/haha /mnt/xixi/haha1/haha2/haha_newname
mv /mnt/xixi/haha1/haha2/haha_newname /mnt/xixi/haha1/
```

**删除**
- 删除目录：`rm -rf`
- 删除普通文件：`rm -rf`

**查找包含关键字的文件**

```bash
grep -r root /          # 递归过滤目录下文件中包含 root 的行
grep -ril ^root$ /      # 只显示含关键字的文件名
grep -rin root /        # 显示行号
```

| 选项 | 说明 |
|---|---|
| `-n` | 显示关键字在该文件中的第几行 |
| `-l` | 只显示含有关键字的文件名称 |
| `-r` | 递归过滤目录下文件里的行 |

## 三、数据输入与重定向

`echo` 需配合重定向符使用：

```bash
echo 123 > 文件名
```

**重定向操作符**
1. **输出重定向**：`>` 覆盖，`>>` 追加
2. **输入重定向**：`<`、`<<`

- 前面是 `1>` 表示标准输出，`2>` 表示错误输出
- 需要丢掉输出时，重定向到 `/dev/null`
- **标准输入重定向 `<<` 并不表示追加**，而是表示输入结束，作为一个结束符

示例：

```bash
[root@localhost ~]# cat > file1 <<end
> 123
> end
```

## 四、vim 编辑技巧

**将 /etc/passwd 内容读取到 haha 文件（末行模式）**

```vim
:r /etc/passwd        # 复制（读入）文件
:set nu               # 显示行号
:set nonu             # 取消显示行号
:s /old/new           # 将当前行第一个 old 替换为 new
:s /old/new/g         # 将当前行所有 old 替换为 new
:n1,n2 s/old/new/g    # 在 n1~n2 行范围内替换所有 old
:% s/old/new/g        # 将整个文件的 old 替换为 new
```

**可视化模式**

按 `Ctrl+v` 进入可视化模式，通过光标移动选择文本：
- `y`：把文本提取到缓冲区（复制）
- `c`：剪切
- `p`：在光标后粘贴
- `P`：在光标前粘贴

**查看行**

```bash
head -7 /mnt/xixi/haha | tail -1    # 查看第七行
head -7 /mnt/xixi/haha | cat -n     # 查看前七行
```

## 五、SSH 远程连接

### 1. SSH 基础概念
- **定义与作用**：SSH 是一种加密网络协议，用于在不安全网络中建立安全远程连接，替代明文传输的 Telnet、FTP 等协议
- **核心功能**：远程服务器登录、命令执行、文件传输（SCP/SFTP）、端口转发等
- **版本差异**：SSH-1 为早期版本、存在安全漏洞已不推荐；SSH-2 是目前主流版本，采用更安全的加密算法与认证机制，与 SSH-1 不兼容

**远程连接服务器**：通过文字或图形接口远程登录系统，登录后取得可操作的主机接口（shell），操作感觉就像坐在系统前面一样。

### 2. SSH 客户端工具

**命令行工具**
- OpenSSH（Linux/macOS 内置）：`ssh`（登录）、`scp`（文件传输）、`sftp`（交互式文件传输）、`ssh-keygen`（生成密钥对）等
- PuTTY（Windows）：图形化工具，支持 SSH、Telnet 等协议

**图形化工具**
- Xshell、FinalShell：功能丰富，支持多标签、会话管理、密钥认证
- FileZilla：通过 SFTP 协议管理远程文件

### 3. SSH 服务器配置

**主流服务器软件**：OpenSSH Server（Linux 主流）、Dropbear（轻量级，适合嵌入式设备）

**核心配置文件**
- `/etc/ssh/sshd_config`（服务器配置）
- `/etc/ssh/ssh_config`（客户端默认配置）

**关键配置项**
- 端口修改（`Port`，默认 22，建议自定义提高安全性）
- 禁用密码认证（`PasswordAuthentication no`），强制公钥认证
- 禁用 root 直接登录（`PermitRootLogin no`），通过普通用户 sudo 提权
- 限制允许登录的用户（`AllowUsers`）或组（`AllowGroups`）

### 4. 实验：修改 SSH 端口号

```bash
[root@server1 ~]# vim /etc/ssh/sshd_config
Port 2222

[root@server1 ~]# systemctl disable --now firewalld
[root@server1 ~]# setenforce 0
[root@server1 ~]# getenforce
Permissive

[root@server1 ~]# systemctl restart sshd
```
修改端口后，客户端需使用新端口进行测试连接。
