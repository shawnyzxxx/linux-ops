# RHCSA第二次作业

## 文章导读
本篇是 RHCSA 第二次作业，围绕**系统信息查询、主机名修改、命令查找路径、软链接与文件操作**等基础命令展开，是 Linux 入门阶段巩固命令行基本功的练习，适合刚接触 RHEL 系统的读者。

## 一、作业题目
1. **#08** 查看系统合法 Shell
2. **#09** 查看系统发行版版本
3. **#10** 查看系统内核版本
4. **#11** 临时修改主机名
5. **#12** 查看系统指令的查找路径
6. **#13** 查看 `passwd` 指令的执行路径
7. **#14** 为 `/yasuo/ssh_config` 文件在 `/mulu` 目录下创建软链接，链接名为 `ssh_config.link`
8. **#15** 创建目录 `/mulu`，重命名并移动 `ssh_config.link`
9. **#16** 找到根目录下的所有块设备文件
10. **#17** 将 `/etc/passwd` 和 `/etc/ssh/sshd_config` 复制到 `/root/etc/` 目录下
11. **#18** 复制 `/var/log/messages` 到 `/root` 目录下

## 二、参考命令
**#08 查看系统合法 Shell**
```bash
cat /etc/shells
```

**#09 查看系统发行版版本**
```bash
cat /etc/redhat-release
```

**#10 查看系统内核版本**
```bash
uname -r
```

**#11 修改主机名**
```bash
# 临时修改（重启后失效）
hostname shawn

# 永久修改
hostnamectl set-hostname shawn

# 查看主机名
hostnamectl
```

**#12 查看系统指令查找路径**
```bash
echo $PATH
```

**#13 查看 passwd 指令执行路径**
```bash
which passwd
type passwd
```

**#14 创建软链接**
```bash
ln -s /yasuo/ssh_config /mulu/ssh_config.link
```
> `ln -s` 创建符号链接（软链接），源文件变化时链接内容会同步。

**#15 创建目录并重命名移动**
```bash
mkdir -p /mulu
mv /mulu/ssh_config.link /mulu/ssh_config.renamed
```

**#16 查找根目录下的块设备文件**
```bash
lsblk
find / -type b
```

**#17 / #18 复制文件**
```bash
mkdir -p /root/etc
cp /etc/passwd /etc/ssh/sshd_config /root/etc/
cp /var/log/messages /root/
```
