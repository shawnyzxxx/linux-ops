# 第八章用户管理作业

## 文章导读
本篇是 Linux 用户与用户组管理章节的作业记录，涵盖使用 `useradd` 创建用户、`usermod` 修改登录 Shell、`groupadd` 创建用户组，以及主组/附加组的分配，适合学习 Linux 账号管理基础的读者。

## 一、创建用户
使用 `useradd` 命令创建普通用户：

```bash
useradd user
useradd sarah
useradd wukong
```

## 二、修改用户登录 Shell
将用户 `wukong` 的登录 Shell 改为 `/bin/sh`：

```bash
sudo usermod -s /bin/sh wukong
```

随后切换到该用户验证：

```bash
sudo su - wukong
ls /root
```
> `usermod -s` 用于修改用户的登录 Shell，可按安全要求把 Shell 调整为受限制的 `/bin/sh`。

## 三、用户组管理
创建用户组并分配主组、附加组：

```bash
groupadd shenxian
groupadd xiyouji

# 创建用户 wujing，主组为 shenxian，附加组为 xiyouji
useradd -g shenxian -G xiyouji wujing

# 创建用户 yangjian，主组为 shenxian
useradd -g shenxian yangjian
```

**参数说明：**
- `-g`：指定用户的主用户组（主要组）
- `-G`：指定用户的附加用户组（次要组，可多个）

## 四、小结
本次作业完整演练了 Linux 用户与用户组的创建与配置。`useradd -g` 与 `useradd -G` 的区别是高频考点：主组决定用户归属，附加组用于授权复用，理解二者关系对权限管理至关重要。
