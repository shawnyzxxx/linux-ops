# RHCSA第四次作业

## 文章导读
本篇是 RHCSA 第四次作业，全部使用 **vim 编辑器** 完成，涉及创建文件、写入内容、按条件删除行、开启行号等编辑技巧，适合正在练习 Linux 文本编辑的读者。

## 一、练习要求
1. **#44** 在 `/tmp` 文件夹下创建文件 `newfile`，并在首行输入日期时间
2. **#45** 将 `/boot/grub2/grub.cfg` 的内容读入到 `newfile` 中（读入到日期的下一行，即第 2 行）
3. **#46** 查找 `newfile` 中包含 `#` 号字符的行，将整行删除
4. **#47** 开启 VI 的行号提示功能

## 二、操作步骤
**#44 创建文件并写入日期时间**
```bash
vim /tmp/newfile
```
进入编辑器后在首行输入当前日期时间，例如 `2024-10-30 21:16`，然后保存退出。

**#45 将 grub.cfg 内容读入当前文件**
在 `newfile` 的编辑模式中执行：
```vim
:r /boot/grub2/grub.cfg
```
> `:r` 即 `:read`，会把指定文件的内容读入到光标所在行的下一行。

**#46 删除所有含 # 号的行**
```vim
:g/#/d
```
> `:g/#/d` 表示全局（global）匹配包含 `#` 的行并执行删除（delete）。

**#47 开启行号**
```vim
:set nu
```
> `:set nu` 即 `set number`，开启行号显示；想关闭用 `:set nonu`。

## 三、小结
通过本作业可以熟练掌握 vim 的 `:r` 读入文件、`:g//d` 全局删除、`:set nu` 显示行号等常用命令，这些都是日常编辑配置文件时非常实用的技巧。
