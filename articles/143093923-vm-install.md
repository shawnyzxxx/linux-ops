# 虚拟机的安装和创建

## 文章导读
本文记录在 VMware 中创建一台 RHEL 9.3 虚拟机、安装操作系统、配置网络并远程登录的完整流程，适合刚接触 Linux 运维、需要搭建学习环境的同学参考。

## 一、创建虚拟机
在 VMware 中新建虚拟机，命名为 **rhel9.3_666**。建议在创建时分配足够的内存和磁盘空间（学习环境 2G 内存、20G 磁盘即可）。

## 二、安装操作系统
在虚拟机 **rhel9.3_666** 中安装 RHEL 9.3 操作系统，按安装向导完成语言、时区、root 密码和软件包选择。

## 三、检查网络并创建快照
安装完成后检查网卡是否能正常获取 IP 地址：

```bash
ip addr
```

确认网络正常后，为这台虚拟机**创建快照**。快照可以作为学习的回滚点，方便在后续误操作或实验失败时快速恢复。

## 四、远程登录虚拟机
拿到虚拟机的 IP 地址后，可以通过两种方式远程连接：

**方式一：使用 Xshell**
打开 Xshell，新建会话并输入主机 IP 地址，按提示完成连接与认证。

**方式二：使用系统自带的 SSH 客户端**
在控制面板或终端中使用 SSH 协议连接：

```bash
ssh root@<虚拟机IP>
```

输入登录用户账号与密码，连接成功后即可进入虚拟机进行日常操作。

> 提示：远程连接前务必确认虚拟机网络已配置、防火墙放行 SSH（默认 22 端口），否则会出现连接超时。
